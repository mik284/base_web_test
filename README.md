# BASEPOINTCLOUD WEBSITE

- One Platform to Run Your Entire Business
- Manage sales, inventory, accounting, and payments from a single, unified dashboard built specifically for African businesses to scale effortlessly.

## Tech Stack

- Umi Max
- React
- TypeScript
- Ant Design
- Tailwind CSS
- Pnpm

## Getting Started

```bash
pnpm install
pnpm dev
```
